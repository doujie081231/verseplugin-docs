示例插件工程 ​

以市场的 verse-server-host（本地开服）插件的包结构为参照，展示一个真实、最小的字段布局。

目录结构 ​

text
verse-server-host/
└── plugin.json

plugin.json ​

json
{
    "id": "verse-server-host",
    "name": "本地开服",
    "version": "1.0.0",
    "category": "server",
    "author": "VersePC2",
    "description": "本地一键开服功能，支持在启动器内创建并启动 Minecraft 服务器。",
    "main": "index.js"
}

该插件包的实际市场条目如下（本地与远端双重展示）：

  • zip：https://gitee.com/doujie081231/verseplugin/raw/master/verse-server-host.zip
  • index.json 条目：
json
{
  "id": "verse-server-host",
  "name": "本地开服",
  "version": "1.0.0",
  "category": "server",
  "author": "VersePC2",
  "description": "本地一键开服功能，支持在启动器内创建并启动 Minecraft 服务器。",
  "icon": "",
  "downloadUrl": "https://gitee.com/doujie081231/verseplugin/raw/master/verse-server-host.zip",
  "sha256": "9d92741d45b9b81c2c16f7f12aac72772448bbb03860c3249f2130899a4be820",
  "size": 321
}

TIP

category: "server" 的插件在当前版本会在插件市场的“功能”列表一并展示。

把它改造成你自己的插件 ​

  1. 复制 verse-server-host/ 目录并改名。
  2. 修改 plugin.json：换掉 id（唯一）、name、version、描述与 category。
  3. 按需加入 main 运行脚本或其他资源文件。
  4. 重新打包并发布到市场。
