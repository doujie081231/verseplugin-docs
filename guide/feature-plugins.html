功能插件：新增页面与卡片 ​

功能插件分两种，"新增页面"型与"插入卡片"型。判断方法：

类型需要 SVG 图标？效果
新增页面需要在侧边栏生成按钮，点击进入独立整页（类似"本地开服"）
插入卡片不需要直接在某个现有页面里插入一张卡片/区块

组件统一用 Vue 3（与启动器前端一致），脚本放到插件目录，由插件运行时加载并挂载。

类型 A：新增页面（侧边栏 + SVG + Vue） ​

1. 目录结构 ​

text
my-feature/
├── plugin.json
├── page.svg          # 侧边栏按钮图标（SVG）
└── page.js           # 页面 Vue 组件

2. plugin.json ​

json
{
  "id": "my-feature",
  "name": "我的功能",
  "version": "1.0.0",
  "category": "function",
  "author": "你",
  "description": "新增一个独立页面。",
  "ui": {
    "pages": [
      { "id": "main", "title": "我的功能", "icon": "page.svg", "component": "page.js" }
    ]
  }
}

3. SVG 图标（page.svg） ​

侧边栏按钮会读取该 SVG 并嵌入。要求：

  • 是完整的 <svg> 片段，建议 viewBox="0 0 24 24"。
  • 使用 stroke="currentColor" 以跟随启机按钮配色（也可指定固定颜色）。
  • 尽量单色、简洁，尺寸按 24x24 设计，缩放即可。
xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
  <rect x="2" y="3" width="20" height="8" rx="2" ry="2"/>
  <rect x="2" y="14" width="20" height="8" rx="2" ry="2"/>
</svg>

4. Vue 组件（page.js） ​

组件注册到固定命名 window.VersePC["Plugin_<插件id>_<页面id>"]，与 ui.pages[].id 对应。

js
(function () {
  window.VersePC = window.VersePC || {};
  window.VersePC["Plugin_my-feature_main"] = {
    data() {
      return { count: 0 };
    },
    methods: {
      add() { this.count++; }
    },
    template: `
      <div class="page-header">
        <h2>我的功能</h2>
        <p class="page-subtitle">由插件运行时注册的独立页面</p>
      </div>
      <div style="padding:0 24px;">
        <button class="btn btn-accent" @click="add">点击：{{ count }}</button>
      </div>
    `
  };
})();

要点：

  • 使用启动器已有的工具类样式（class="page-header"、class="btn" 等）保持观感一致。
  • 可访问启动器前端全局对象与函数（如 navigateToPage、window.bridge），实现跨页跳转等，见 个性化 → main 脚本。

5. 效果 ​

安装后侧边栏出现"我的功能"按钮（带 SVG），点击进入新页面。

类型 B：插入卡片 ​

1. plugin.json ​

json
{
  "id": "my-card",
  "name": "我的卡片",
  "version": "1.0.0",
  "category": "function",
  "author": "你",
  "description": "往现有页面插入一张卡片。",
  "ui": {
    "cards": [
      { "id": "widget", "anchor": "#page-mods .mod-list", "component": "card.js" }
    ]
  }
}

字段说明：

  • anchor：CSS 选择器，指向要插入位置的容器。插件运行时会等该选择器出现后把卡片追加进去。
  • component：卡片 Vue 组件文件。
  • id：可选，用于区分同一插件多张卡片。

2. Vue 组件（card.js） ​

注册名 window.VersePC["Plugin_<插件id>_card_<卡片id或组件文件名>"]。

js
(function () {
  window.VersePC = window.VersePC || {};
  window.VersePC["Plugin_my-card_card_widget"] = {
    template: `
      <div class="plugin-card-slot" style="padding:14px;margin:12px;border:1px solid var(--border-color);border-radius:12px;background:var(--bg-secondary);">
        <div style="font-weight:600;">我的卡片</div>
        <div style="font-size:12px;color:var(--text-muted);">插入在现有页面上的内容。</div>
      </div>
    `
  };
})();
  • 卡片不需要 SVG 图标。
  • 建议自带内边距与边框样式，避免与宿主页面冲突。
