个性化 ​

个性化插件不止一种形态。因为它运行在启动器同一前端环境里，所以整个软件前端都可以自定义开发——改观感、加界面、做挂件都行。

推荐用 Vue 模板编写界面，用 main 脚本做任意定制。

1. plugin.json 骨架 ​

json
{
  "id": "my-personalize",
  "name": "我的个性化",
  "version": "1.0.0",
  "category": "personalize",
  "author": "你",
  "description": "自定义启动器外观与添加挂件。",
  "ui": {
    "main": "main.js",       // 任意前端定制（可选）
    "style": "theme.css",     // 注入全局 CSS（可选）
    "pages": [],              // 同功能插件，见 feature-plugins
    "cards": [],              // 同功能插件
    "pet": { "component": "pet.js" }  // 宠物挂件（可选）
  }
}

2. main 脚本：整个前端都可以自定义 ​

ui.main 指向的 .js 会在启动器加载插件时执行，与启动器前端同一 JavaScript 环境。因此你能：

  • 读写全局对象：window.VersePC、navigateToPage、window.bridge 等
  • 直接操作 DOM、注入样式、监听事件
  • 创建/销毁任意界面元素
js
(window.VersePC = window.VersePC || {}).Plugin_my-personalize_main = {};
// main.js：示例——启动后给侧边栏加一个文字徽标
window.addEventListener('DOMContentLoaded', function () {
  var logo = document.querySelector('.sidebar .sidebar-footer');
  if (logo) {
    var tag = document.createElement('div');
    tag.textContent = 'RAD ' + (new Date().getFullYear());
    tag.style.cssText = 'text-align:center;font-size:10px;color:var(--text-muted);padding:4px;';
    logo.appendChild(tag);
  }
});

WARNING

main 脚本拥有完整前端能力，也意味着风险。请只在受信任的环境使用，并按 提交审核（GPLv3） 走官方上架。

3. style：注入全局 CSS ​

ui.style 指向的 .css 会以 <style> 注入全局，适合做主题/字号/配色覆盖。可结合启动器的 CSS 变量（--accent、--bg-primary 等）做主题：

css
/* theme.css：把侧边栏高亮改成自定义紫 */
:root { --accent: #7c5cff; }

4. 宠物挂件 ​

ui.pet 让个性化插件渲染一个挂件浮层（如桌宠）。挂件也是 Vue 组件，可展示图片/动画并交互。

目录与声明 ​

text
my-personalize/
├── plugin.json
└── pet.js           # 挂件 Vue 组件
json
"ui": { "pet": { "component": "pet.js" } }

挂件组件（pet.js） ​

注册名 window.VersePC["Plugin_<插件id>_pet"]。挂件容器固定在启动器窗口右下角，组件内部定义显示与交互（pointer-events 需在内容上自行开启）：

js
(function () {
  window.VersePC = window.VersePC || {};
  window.VersePC["Plugin_my-personalize_pet"] = {
    data() { return { bouncy: false }; },
    methods: {
      poke() { this.bouncy = true; setTimeout(() => (this.bouncy = false), 400); }
    },
    template: `
      <div @click="poke" style="pointer-events:auto;cursor:pointer;text-align:center;"
           :style="bouncy ? 'animation:plugin-bounce .4s' : ''">
        <img src="https://trae-api-cn.mchost.guru/api/ide/v1/text_to_image?prompt=cute%20chibi%20cat%20pet%20sticker&image_size=square" width="72" height="72" style="border-radius:16px;" alt="pet">
        <div style="font-size:11px;color:var(--text-muted);">点我！</div>
      </div>
    `
  };
})();

制作方式建议 ​

  • 图片/兔： 准备一组宠物帧（PNG/WebP/GIF）或单张贴纸图。
  • 逐帧动画： 在组件里用 setInterval 切换多帧图片，或使用 CSS steps() 精灵图动画。
  • 交互： 用 Vue @click/@mousemove 绑定；浮层外层 pointer-events:none，内容自行开启。
  • 尺寸： 建议右下角挂件控制在 60–120px 内，避免遮挡操作区。

（示例用到了内置的图片生成占位；正式上架请使用可稳定访问的图片资源。）
