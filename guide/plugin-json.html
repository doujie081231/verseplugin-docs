plugin.json 字段 ​

plugin.json 必须是 UTF-8 编码的 JSON，位于插件有效根目录。启动器会读取它来判断插件是否合法、用于市场展示与排序。

必填字段 ​

字段类型说明
idstring插件唯一标识，建议 小写字母+连字符（如 hello-verse）。安装后作为目录名 data/plugins/<id>/，必须非空
namestring插件显示名称，市场列表中展示，必须非空
versionstring当前版本号（如 1.0.0），市场据此判断是否有更新，必须非空

WARNING

id、name、version 三者缺一不可，缺任一项都会被判定为不合法插件，无法安装。

可选字段 ​

字段类型说明
categorystring分类，取值 function / personalize / server，详见解说见 分类约定
mainstring插件入口脚本/资源相对路径（如 index.js），供插件运行时加载
descriptionstring插件说明，市场卡片与详情中展示
authorstring作者名
iconstring图标 URL（可选），市场卡片展示；留空时前端用默认分类图标

完整示例 ​

json
{
  "id": "verse-server-host",
  "name": "本地开服",
  "version": "1.0.0",
  "category": "server",
  "author": "VersePC2",
  "description": "本地一键开服功能，支持在启动器内创建并启动 Minecraft 服务器。",
  "main": "index.js"
}

说明 ​

  • 安装到 data/plugins/<id>/plugin.json 后，启动器会额外写入 installedDir 与 installedVersion 两个只读字段用于内部记录，开发者无需关心。
  • 同一 id 重复安装会覆盖旧版本（即"更新"）。
